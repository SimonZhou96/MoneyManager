# 股票池筛选功能实现总结

## 功能概述

成功实现了"股票池筛选"功能，允许用户将股票池中的股票投入到选股器中进行策略筛选。

## 完成时间

2026-02-26

## 实现的功能

### 1. 新增"股票池"Tab

在前端添加了第三个主 Tab "股票池"，与"自选股"和"筛选条件"并列。

### 2. 股票池选择和加载

用户可以：
- 选择市场（港股/美股/A股）
- 选择股票池类型：
  - **最好股票** - 基于市值、价格、PE、成交量筛选的优质股票
  - **指数成份股** - 主要指数的成份股
  - **行业龙头** - 各行业前5名股票
  - **新股** - 最近两年上市的股票
  - **ETF列表** - 所有ETF和REIT
- 点击"加载股票池"按钮获取数据
- 查看股票池中的股票列表（代码、名称、市值、价格、PE）

### 3. 策略筛选

- 选择时间周期（1d/1w/1m）
- 点击"开始筛选"将股票池中的所有股票投入选股器
- 使用 EMA 突破策略进行筛选
- 实时显示筛选进度
- 显示满足条件的股票

### 4. 结果展示

- 显示筛选结果表格
- 支持结果二次筛选（板块、行业、市值、PE、价格）
- 点击股票代码查看K线图

## 技术实现

### 数据流

```
1. 用户选择市场和股票池类型
   ↓
2. 点击"加载股票池"
   ↓
3. 前端调用 GET /api/stock-pools?market=HK&pool_type=best
   ↓
4. 后端从 stock_pools 表查询数据
   ↓
5. 返回股票列表和更新时间
   ↓
6. 前端渲染股票池表格
   ↓
7. 用户选择时间周期，点击"开始筛选"
   ↓
8. 前端将股票池转换为 watchlist 格式
   ↓
9. 调用 POST /api/screen 提交筛选任务
   ↓
10. 后端使用 EMA 突破策略筛选
   ↓
11. 前端轮询进度，显示实时结果
   ↓
12. 筛选完成，显示结果表格
```

### API 接口

#### GET /api/stock-pools

**参数**:
- `market`: HK/US/A
- `pool_type`: best/index/industry/ipo/etf
- `limit`: 可选，限制返回数量

**返回**:
```json
{
  "stocks": [
    {
      "code": "HK.00700",
      "name": "腾讯",
      "market_cap": 4758071075300,
      "price": 522.5,
      "pe_ratio": 19.935,
      ...
    }
  ],
  "total": 338,
  "last_update": {
    "update_time": "2026-02-26 00:02:29",
    "stock_count": 338,
    "status": "success"
  }
}
```

#### GET /api/stock-pools/types

返回所有股票池类型及说明。

#### GET /api/stock-pools/stats

返回指定市场所有股票池的统计信息。

## 注意事项

### 1. 数据依赖

股票池功能依赖于 `stock_pools` 表中的数据，需要先运行 `fetch_stock_pools.py` 获取数据。

### 2. 更新频率

建议每天收盘后更新股票池数据：
```bash
0 17 * * 1-5 MYSQL_PASSWORD=123456 python3 fetch_stock_pools.py --market HK --pools all
```

### 3. 性能考虑

- 股票池筛选比全市场筛选快得多
- 最好股票池（338只）筛选时间约 1-2 分钟
- ETF列表（413只）筛选时间约 2-3 分钟

### 4. 错误处理

如果股票池数据不存在，前端会提示：
```
该股票池暂无数据，请先运行 fetch_stock_pools.py 获取数据
```
