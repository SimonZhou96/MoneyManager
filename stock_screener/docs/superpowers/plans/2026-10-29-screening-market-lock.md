# 同市场同日全市场任务互斥

已批准的约束：Redis 锁按上海日期、市场区分，无 TTL，不含用户、规则链、周期、股票池；排队/运行/终止中占位；允许跨天重叠；完成、失败或确认终止后校验持有者释放。多市场原子获取，创建/入队失败回滚，Redis 故障拒绝。复用 RQ、现有数据库表、鉴权、错误格式和页面风格。单股、自定义列表、选股规则不变。不新增 resolver/normalize/manager 或通用 helper。

## Task 2: 创建、恢复、执行与终止

创建与恢复先获取 Redis 锁；复用现有 options_json 保存锁与 RQ 尝试标识。数据库状态用条件更新避免重复恢复、取消/启动竞态和旧回调覆盖新执行。保留同条件成功去重，失败/取消后允许重用原 SQL 日锁记录。RQ 执行并逐市场释放。停止回调必须在执行进程退出后收尾；排队取消通过数据库条件更新阻止已出队任务执行。异常状态不凭超时释放。

验证：路由、真实 RQ/独立 Redis 与模拟筛选流程，覆盖取消、失败、完成、恢复、竞争及补偿。所有外部行情、搜索、LLM、飞书调用为 0。
