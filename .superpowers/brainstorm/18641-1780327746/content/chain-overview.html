当前规则链全链路架构（技术指标 + 时事分析 + 宏观五因素打分）

从输入股票池 → 筛选引擎 → 多维分析 → 最终报告的完整数据流

📊 链路总览（5 大阶段）

阶段一：输入 & 准备
股票来源：DB stocks 表 / AKShare API / 自选股 watchlist
基本面补全：市值、PE、PB、行业 → 转为 StockInfo 列表
规则链加载：RuleRepository 从 DB 加载 screening_rule_metadata + screening_rule_chains（JSON DSL）
K线预取判断：检查规则链是否引用 KLINE_IMPLEMENTATIONS，逐股拉取（Futu/YFinance/DB）
⬇️
阶段二：逐股规则评估（RuleEngine.evaluate_stock）
JSON DSL 表达式求值：RuleExpressionEvaluator 解释 and/any/ref/all_enabled/any_enabled

规则分四层并行评估：
① 基础筛选MarketCapFilter, PriceFilter, PEFilter, AvgDailyVolumeFilter, ProfitabilityFilter
② 技术指标ZuoYiStrategizer, EMABreakoutStrategizer, RSIOverbought/Oversold, VolumeSpike, DailyPctChangeBand, TechnicalPatternStrategizer（26种形态）
③ 时事分析CompanyEventHotSectorStrategizer, CompanyEventHotNewsStrategizer → 触发 SignalAnalysis LLM 管线（搜索+多provider AI）
④ 宏观/潜力MarketIntelMacroScoreStrategizer, MacroFactorAnalysisStrategizer, EnterprisePotentialAnalysisStrategizer
⬇️
阶段三：结果聚合 & 评分
每只股票产出：StockFilterResult（passed + filter_outputs 列表）
评分聚合：aggregate_rule_scores() → technical_score + macro_score → final_score
实时写入：每只股票处理完立即 upsert 到 screening_results 表
⬇️
阶段四：报告生成（AI 复核报告）
输入：screening_results 表（通过筛选的股票 + filter_details）
报告结构（5 部分）：
① 核心结论（信号强度、热点匹配、公司催化、信息充分度、主力流出风险）
② 复核结果总览表（综合评分 | 方向判断 | 热点匹配 | 简明结论）
③ 主力流出风险观察（风险等级、信号、资金流向）
④ 热点板块分析
⑤ 个股详细分析
⬇️
阶段五：交付
飞书通知：feishu_notifier.send_screening_result() → Webhook 摘要 + CSV/PDF 文件
CSV 导出：筛选结果 + AI 分析列（30+ 列：信号可靠性、方向判断、利好/风险因素等）
Markdown 报告：analysis_report_path_for_csv() → .md 文件

🔍 五因素评分模型详情（EnterprisePotentialAnalysis）

M

宏观环境 30%

利率(LPR/国债)、通胀(CPI)、增长(PMI/GDP)、货币(M2)、风险(VIX/DXY)

I

行业景气 25%

板块归属、热点标签(LLM注入)、行业周期阶段、政策支持度

C

企业质量 25%

ROIC/ROE、毛利率、净利率、收入增速、负债率 + LLM事件增强

V

估值 10%

PE(TTM/Forward)、PB、PEG、EV/EBITDA

T

市场行为 10%

涨跌幅、Beta、趋势强度、vs均线、波动率
