方案 A 设计 · 第一节：数据流 & 架构变更

核心原则：五因素模型为唯一评分出口，MarketIntel 降级为 LLM 增强数据源

🔄 当前 vs 目标 数据流对比

❌ 当前：双轨评分
轨 A — MarketIntelMacroScore:
SignalAnalysis LLM → MarketIntel Service
→ EvidencePackBuilder（逐股构建证据）
→ MacroEvidencePreprocessor
→ LLM MacroScoreScorer（6维子评分）
→ macro_score + pass/fail
权重: 0.6技术 + 0.4宏观

轨 B — EnterprisePotential:
MacroFactorAnalysisStrategizer
→ MacroSnapshot（宏观因子采集）
+ IndustrySnapshot + CompanySnapshot
+ ValuationSnapshot + TradingSnapshot
→ EnterprisePotentialScorer
→ total_score + BUY/WATCH/SKIP
权重: M30+I25+C25+V10+T10

⚠️ 两轨独立运行，结果各自写入 details，无统一汇总
✅ 目标：统一评分
数据采集层（不变）：
① SignalAnalysis LLM → 时事/热点/新闻
② MarketIntel Service → 市场情报证据
③ MacroFactor Provider → 宏观因子快照
④ Financial Data → 企业财务+估值
⑤ K-line Data → 交易行为指标

统一评分引擎：
EnterprisePotentialScorer（增强版）
├─ MacroScorer + MarketIntel LLM 增强
├─ IndustryScorer + SignalAnalysis 热点注入
├─ CompanyScorer + LLM 事件/新闻增强
├─ ValuationScorer（不变）
└─ TradingScorer + 技术信号增强
→ 唯一输出：total_score + module_scores + decision + holding_period
✅ 单一评分出口，所有数据源均为增强输入
