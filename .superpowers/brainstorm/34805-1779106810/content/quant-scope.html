量化框架第一阶段范围

先选一个 MVP 边界。后续设计会围绕这个边界展开，避免一次性把研究、回测、实盘和期权全量能力混在一起。

A

股票优先回测

先把股票/ETF 策略的历史回测、胜率、盈亏比、净值曲线和交易明细跑通，再接期权。实现最快，数据最稳定。

B

股票 + 期权统一框架

第一版就建立统一信号、撮合、绩效模型；股票先完整落地，期权支持策略回放和受限回测。架构更稳，复杂度中等。

C

期权优先完整回测

围绕期权链、Greeks、IV、DTE、多合约组合、最大亏损和行权风险设计。价值高，但历史期权数据质量是最大风险。

Futu / AKShare / yfinance

信号 -> 撮合 -> 持仓

胜率 / 回撤 / 净值
