🟡 Bug 5（额外发现）：React Flow Edge Handle 错配

所有通过 expressionToFlow() 生成的边都有 sourceHandle: null。 React Flow v12 严格要求边必须指定有效的 source handle ID，否则边不会渲染。

这意味着即使 Bug 1 修好了，画布上的连接线也不会显示，节点之间只能看到孤立的方块。 这解释了为什么你截图里画布看起来"是空的"——可能节点在，但边没有连接。
